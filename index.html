Setup

Get Started in 60 Seconds

No drivers, no installers, no configuration required out of the box.

1

Extract the ZIP

Download mbw9-v3.3.zip and extract all files into a single folder. Keep them together.

2

Launch Counter-Strike 2

Use Fullscreen Windowed (Borderless) or Windowed display mode.

3

Run as Administrator

Right-click External.exe → Run as administrator (required for NTAPI access).

4

Press INSERT

Toggle the configuration menu with INSERT at any time while in-game.
