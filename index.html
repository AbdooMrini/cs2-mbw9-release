Architecture

Built for Ultra-Low Latency

Zero kernel drivers, zero intrusive hooks. Lightweight C++17 design with maximum compiler optimization.

Memory Architecture Usermode NTAPI

Direct NtReadVirtualMemory access from ring 3 without vulnerable third-party kernel drivers.

Overlay Renderer DirectX 11 + ImGui

Hardware-accelerated topmost window with zero input lag and variable refresh rate synchronization.

Entity Cache Rate 125 Hz Seqlock

Multi-threaded atomic snapshot cache reduces operating system memory query overhead by ~25×.

Binary Footprint Statically Linked (/MT)
